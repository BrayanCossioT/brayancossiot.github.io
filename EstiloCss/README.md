# EstiloCss — Imagen Profesional para tu Negocio

Página web de presentación de servicios de diseño gráfico orientado a emprendedores, negocios locales y profesionales que buscan una imagen más profesional para atraer clientes.

## Concepto

No se venden diseños complejos ni branding corporativo. Se ofrecen soluciones rápidas, atractivas y económicas con una filosofía clara:

> *"Ayudo a que tu negocio tenga una imagen profesional para generar más confianza."*

## Servicios

- **Tarjetas de presentación** — Diseño frente y reverso con código QR, redes sociales, logo y fotografías.
- **Banners para redes** — Para WhatsApp, Facebook e Instagram. Promociones, descuentos, productos.
- **Diseño / Adaptación de Logo** — Mejora de resolución, fondo transparente, ajustes de color o creación desde cero (cotización independiente).
